# 🎨 OpenCV Browser-Style Color Picker

A professional browser-like color picker built using Python & OpenCV.

## Features
- HSV color model (like browsers)
- RGB & HEX output
- Smooth mouse dragging
- Dark / Light mode
- Save & copy colors
- Palette history
- Real-time date & time

## Run
```bash
pip install -r requirements.txt
python color_picker.py
